# Black & White Portfolio

A simple, responsive React portfolio with a black-and-white palette and separate routes.

## Pages
- `/` — Home
- `/about` — About and draft skills
- `/projects` — Project cards
- `/contact` — Contact details

## Run locally
1. Install Node.js if it is not already installed.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown in the terminal.

Replace `[Your Name]`, `hello@example.com`, and the draft project details with your own information.
